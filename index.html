스펙트럼 이미지 OCR → PASS/FAIL 판정 → 보고서(docx)

브라우저에서 직접 실행 · AI 미사용(Tesseract OCR) · 각 단계는 버튼을 눌러 진행

1. OCR 추출
2. 판정
3. 보고서

1단계. 이미지 업로드 및 OCR 데이터 추출

이미지 파일을 여기에 끌어놓거나 클릭해서 선택 (여러 장 가능)
OCR 값은 표에서 직접 수정할 수 있습니다(노란색 행 = 교차검증 의심). 단위: W, mW, µW, nW, pW.

2단계. 판정 기준 설정 및 PASS/FAIL 판정

기본 -52. 양수(+)를 넣으면 측정값이 크게 올라가니 부호를 확인하세요.

3단계. 보고서(docx) 생성

제어 챗봇
예) "OCR 실행해줘", "CF를 -50으로 바꾸고 판정해줘", "담당자는 홍길동, 보고서 만들어줘"
이미지 업로드는 왼쪽에서 직접 해주세요. 불확실한 값은 임의로 확정하지 않습니다.
